# 麦麦防过期管家（McExpiryGuard）

> 帮你盯住快过期的积分和优惠券，别让它们悄悄浪费。
> 本项目为「麦当劳程序员创意开发大赛（1024 程序员节）」参赛作品，基于麦当劳 MCP 能力开发。

## 它解决什么问题

麦当劳会员账户里，积分会过期、优惠券会过期、领了不用的「麦麦省」券更是经常白领。大多数人根本记不住哪张券哪天到期，结果就是：

- 攒了好久的积分，某天打开发现已经清零；
- 领了一堆券，真正想用的时候发现昨天刚过期；
- 明明有「即将过期积分」可以兑换，却从来没人提醒你。

「麦麦防过期管家」就是帮你把这些**不起眼、但反复发生的隐性浪费**管起来：它读取你的真实账户数据，告诉你「现在有几样东西快过期了、该怎么花最划算」。

## 核心功能

| 功能 | 说明 | 主要使用的 MCP 工具 |
| --- | --- | --- |
| ① 账户体检 | 一键查看积分余额 / 冻结积分 / 即将过期积分，以及名下优惠券的过期时间 | `query-my-account`、`query-my-coupons` |
| ② 过期倒计时 | 对每项「即将过期」的积分和券做分级预警（30 天 / 7 天 / 3 天 / 今天） | `now-time-info` + 本地计算 |
| ③ 聪明花 | 把「快过期的资源」与「当前活动 / 门店优惠 / 可兑换商品」匹配，给出 3 个「现在花掉最划算」的方案并算好实付价 | `campaign-calendar`、`query-store-coupons`、`mall-points-products`、`calculate-price` |
| ④ 一键领券（需确认） | 查看可领的「麦麦省」券，用户确认后才一键领取 | `available-coupons`、`auto-bind-coupons` |
| ⑤ 体检报告卡 | 生成一张可分享的「账户体检卡」（HTML 可视化） | 由本项目 `src/index.html` 渲染 |

## 安装方法

### 前置条件

1. 注册并激活麦当劳 MCP Token：访问 <https://open.mcd.cn/mcp>，手机号登录 → 控制台 → 激活，复制 Token。
2. 一个支持 MCP（Streamable HTTP 协议）的客户端，推荐腾讯 WorkBuddy。

### 方式一：作为 WorkBuddy Skill 使用（推荐）

1. 在 WorkBuddy 左侧边栏【专家·技能·连接器】→【连接器】→【自定义连接器】→【配置 MCP】。
2. 粘贴本仓库 `mcp-config.example.json` 的内容，并把 `YOUR_MCP_TOKEN` 替换为你自己的 Token，保存并启用 `mcd-mcp`。
3. 把本仓库的 `SKILL.md` 内容作为系统提示 / 技能说明交给 WorkBuddy。
4. 在对话框输入：**「帮我做一次麦麦账户体检」**，即可开始。

### 方式二：独立运行报告卡生成器

报告卡生成器是纯前端、零依赖的静态页面，可离线打开：

1. 直接双击 `src/index.html`（或在浏览器打开）。
2. 在左侧输入体检数据（或粘贴一段账户体检 JSON），右侧实时生成「账户体检卡」。
3. 支持导出为图片用于分享。

## 使用示例

```
用户：帮我做一次麦麦账户体检，重点看有没有快过期的。
管家：
  📊 账户体检报告
  · 可用积分 1,280 分（其中 200 分将在 6 天后过期 ⚠️）
  · 名下优惠券 5 张，其中 2 张即将过期：
      - 「麦辣鸡腿堡 5 折券」还剩 3 天
      - 「任意早餐套餐立减 3 元」今天最后一天 🔴
  💡 聪明花建议：
      1. 今天用「早餐立减 3 元」券买早餐，实付 6.9 元（原价 9.9）
      2. 用 200 即将过期积分兑换「中杯咖啡券」，避免清零
      3. 3 天内用掉「5 折券」，比直接买省 9.5 元
  要我把这份报告生成成可分享的体检卡吗？
```

## 目标用户

- **麦当劳会员 / 麦门常客**：积分和券多、记不住过期时间的用户；
- **上班族**：通勤路上顺手买早餐、下午茶，券经常「领了不用」；
- **「麦麦省」领券党**：习惯一键领券、但从不看有效期的用户；
- 任何想「把每一分积分、每一张券花在刀刃上」的普通消费者。

## 合规与安全

- 本项目**默认只使用只读接口**；涉及副作用的操作（`auto-bind-coupons` 一键领券、`create-order` 下单）均要求用户显式确认后才执行。
- Token 只通过环境变量占位符引用，仓库中不含任何真实凭证。
- 餐品信息、价格与供应状态以麦当劳官方渠道实时结果为准。
